# Credit & Debt Recovery Tracker

A secure, client-side personal financial dashboard designed to track credit scores, debt payoff milestones (Jefferson Capital & Capital One), loan statuses, and weekly progress check-ins.

## Features
- **Local Privacy:** All sensitive data (balances, notes, milestones) is stored securely in your browser's local storage (`localStorage`). Nothing sensitive is ever uploaded to GitHub.
- **Cross-Device Accessible:** Hosted via GitHub Pages so it can be opened easily on a desktop browser or pinned to a smartphone home screen.
- **Live Tracking:** Real-time updates for recovery goals and structured milestone checklists.

## Running Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Safari, Edge).
